# Environment Variables Reference

This document lists all environment variables that can be set in the root `.env` file for Docker deployment.

## 📍 Location

All variables go in the **root `.env` file** (same directory as `docker-compose.prod.yml`).

## 🔧 Backend Variables

| Variable | Default | Description |
|----------|---------|-------------|
| `NODE_ENV` | `production` | Node.js environment |
| `PORT` | `3000` | Backend server port |
| `JWT_SECRET` | *(required)* | Secret key for JWT tokens (auto-generated by deploy script) |
| `JWT_EXPIRE` | `24h` | JWT token expiration time |
| `AI_SERVICE_URL` | `http://ai-service:8000` | Internal AI service URL |
| `FRONTEND_URL` | `https://spel.vidyutai.in` | Frontend URL for Socket.IO CORS |
| `CORS_ORIGIN` | `https://spel.vidyutai.in,...` | Allowed CORS origins |
| `DATABASE_URL` | *(empty)* | PostgreSQL connection string (optional) |
| `POSTGRES_URL` | *(empty)* | Alternative PostgreSQL URL (optional) |
| `POSTGRES_HOST` | *(empty)* | PostgreSQL host (optional) |
| `POSTGRES_PORT` | *(empty)* | PostgreSQL port (optional) |
| `POSTGRES_USER` | *(empty)* | PostgreSQL user (optional) |
| `POSTGRES_PASSWORD` | *(empty)* | PostgreSQL password (optional) |
| `POSTGRES_DB` | *(empty)* | PostgreSQL database name (optional) |

**Note:** If PostgreSQL variables are not set, the backend uses SQLite (default).

## 🤖 AI Service Variables

### Required (for AI features)
| Variable | Default | Description |
|----------|---------|-------------|
| `GROQ_API_KEY` | *(empty)* | **Important:** Groq API key for AI insights and explanations |
| `OPENAI_API_KEY` | *(empty)* | OpenAI API key (optional, if using OpenAI) |

### Server Configuration
| Variable | Default | Description |
|----------|---------|-------------|
| `API_HOST` | `0.0.0.0` | API server host |
| `API_PORT` | `8000` | API server port |
| `DEBUG` | `False` | Debug mode |
| `PYTHON_ENV` | `production` | Python environment |
| `LOG_LEVEL` | `INFO` | Logging level (DEBUG, INFO, WARNING, ERROR) |

### Security
| Variable | Default | Description |
|----------|---------|-------------|
| `SECRET_KEY` | `default-secret-key...` | Secret key for security (change in production!) |
| `ALGORITHM` | `HS256` | JWT algorithm |
| `ACCESS_TOKEN_EXPIRE_MINUTES` | `30` | Access token expiration (minutes) |

### Optional: External Services
| Variable | Default | Description |
|----------|---------|-------------|
| `MONGODB_URI` | *(empty)* | MongoDB connection string (if using MongoDB) |
| `INFLUXDB_URL` | *(empty)* | InfluxDB URL (if using InfluxDB) |
| `INFLUXDB_TOKEN` | *(empty)* | InfluxDB token |
| `INFLUXDB_ORG` | `vidyutai` | InfluxDB organization |
| `INFLUXDB_BUCKET` | `energy_data` | InfluxDB bucket name |
| `KAFKA_BOOTSTRAP_SERVERS` | *(empty)* | Kafka bootstrap servers (if using Kafka) |
| `KAFKA_CONSUMER_GROUP` | `vidyutai-ai-service` | Kafka consumer group |
| `KAFKA_TOPIC_ENERGY_DATA` | `energy-data` | Kafka topic for energy data |
| `KAFKA_TOPIC_ANOMALIES` | `energy-anomalies` | Kafka topic for anomalies |

### Model Settings
| Variable | Default | Description |
|----------|---------|-------------|
| `MODEL_PATH` | `./app/ml-models` | Path to ML models directory |
| `ANOMALY_DETECTION_MODEL` | `isolation_forest_model.pkl` | Anomaly detection model filename |
| `PREDICTION_MODEL` | `energy_prediction_model.pkl` | Energy prediction model filename |

## 🌐 Frontend Variables

Frontend variables are set as **build arguments** in `docker-compose.prod.yml` and cannot be changed via `.env` file. They are:

- `VITE_API_BASE_URL` - Backend API URL
- `VITE_AI_BASE_URL` - AI Service URL
- `VITE_WS_URL` - WebSocket URL

These are hardcoded for production deployment.

## 📝 Example Root `.env` File

```bash
# Production Environment
NODE_ENV=production
DOMAIN=spel.vidyutai.in

# Backend
PORT=3000
JWT_SECRET=your-generated-secret-here
JWT_EXPIRE=24h
FRONTEND_URL=https://spel.vidyutai.in
CORS_ORIGIN=https://spel.vidyutai.in,https://api-be.vidyutai.in,https://api-python-be.vidyutai.in

# AI Service - Required for AI features
GROQ_API_KEY=your-groq-api-key-here
SECRET_KEY=your-secret-key-here
LOG_LEVEL=INFO

# Optional: PostgreSQL (if using instead of SQLite)
# DATABASE_URL=postgresql://user:password@host:5432/vidyutai
# Or use individual variables:
# POSTGRES_HOST=localhost
# POSTGRES_PORT=5432
# POSTGRES_USER=postgres
# POSTGRES_PASSWORD=password
# POSTGRES_DB=vidyutai

# Optional: External services (if using)
# MONGODB_URI=mongodb://localhost:27017/vidyutai
# INFLUXDB_URL=http://localhost:8086
# INFLUXDB_TOKEN=your-token
```

## 🚀 Deployment Script

The deployment script (`infrastructure/aws/deploy-ec2.sh`) automatically creates a minimal `.env` file with:

```bash
NODE_ENV=production
JWT_SECRET=<auto-generated>
DOMAIN=spel.vidyutai.in
```

You can add additional variables to the root `.env` file after running the deployment script.

## ⚠️ Important Notes

1. **GROQ_API_KEY**: Required for AI insights and explanations. Without it, the AI service will use fallback responses.

2. **JWT_SECRET**: Must be a strong, random secret. The deployment script generates this automatically.

3. **SECRET_KEY**: Change from default in production for security.

4. **PostgreSQL**: Optional. If not set, the backend uses SQLite (default).

5. **External Services**: MongoDB, InfluxDB, Kafka are optional. Only set if you're using them.

6. **Frontend Variables**: Cannot be changed via `.env` - they're build-time arguments.

## 🔒 Security

- Never commit `.env` file to Git
- Use strong, random secrets
- Rotate secrets regularly
- Use different secrets for development and production
