# Planning Wizard - Calculation Formulas

This document contains all the formulas used in the Planning Wizard for technical sizing, economic analysis, and emissions calculations. These formulas match the Flask-based solar-battery-calculation implementation exactly.

**Last Updated:** Based on `ai-service/app/api/endpoints/planning.py` implementation (Flask-compatible - 2025)

---

## 1. TECHNICAL SIZING FORMULAS

### 1.1 Basic Constants and Load Calculations

**Local Load (kW)**
```
local_load = total_daily_energy_kwh / 24
```

**Day/Night Energy Split**
```
day_time_energy = total_daily_energy_kwh × (7.03 / 13.01)
night_time_energy = total_daily_energy_kwh × (1 - 7.03 / 13.01)
```

**Solar Insolation**
```
daily_solar_insolation = 5.02 kWh/m²/day
```

---

### 1.2 Efficiency Factors

**Component Efficiencies:**
- `n_module = 0.97` - Module efficiency
- `n_temperature = 0.89` - Temperature derating
- `n_dust = 0.95` - Dust derating
- `n_inverter = 0.9` - Inverter efficiency
- `n_dcdc = 0.95` - DC-DC converter efficiency
- `n_charging = 0.9` - Battery charging efficiency
- `n_discharging = 0.9` - Battery discharging efficiency

**Combined Efficiencies:**
```
n_panel = n_module × n_temperature × n_dust = 0.97 × 0.89 × 0.95 = 0.8207
n_panel = 1  # Flask explicitly overrides to 1 (used in all calculations)
n_battery_roundtrip = n_charging × n_discharging = 0.9 × 0.9 = 0.81
```

**⚠️ IMPORTANT:** In all formulas below, `n_panel = 1` is used (not the calculated 0.8207). This matches the Flask implementation exactly.

**Battery Depth of Discharge:**
```
battery_dod = 0.8 (80%)
```

**Battery Nominal Voltage:**
```
battery_nominal_voltage = 12 V
```

---

### 1.3 Solar Panel Sizing

**Energy Generated by PV System:**
```
# Note: n_panel = 1 (Flask override)
pv_energy_gen = (day_time_energy / (n_panel × n_inverter × n_dcdc)) + 
                (night_time_energy / (n_panel × n_inverter × n_dcdc × n_battery_roundtrip))
pv_energy_gen = (day_time_energy / (1 × 0.9 × 0.95)) + 
                (night_time_energy / (1 × 0.9 × 0.95 × 0.81))
pv_energy_gen = (day_time_energy / 0.855) + (night_time_energy / 0.69255)
```

**Peak Power of PV System:**
```
pv_peak_power = pv_energy_gen / daily_solar_insolation
```

**Example:**
- If `day_time_energy = 27.03 kWh` and `night_time_energy = 22.97 kWh`
- `pv_energy_gen = (27.03 / (1 × 0.9 × 0.95)) + (22.97 / (1 × 0.9 × 0.95 × 0.81))`
- `pv_energy_gen = (27.03 / 0.855) + (22.97 / 0.69255) = 31.61 + 33.17 = 64.78 kWh`
- `pv_peak_power = 64.78 / 5.02 = 12.90 kW`

---

### 1.4 Battery Sizing

**Battery Energy (kWh):**
```
# Note: n_panel = 1 (Flask override)
battery_energy = night_time_energy / (n_panel × n_inverter × n_dcdc × n_battery_roundtrip × battery_dod)
battery_energy = night_time_energy / (1 × 0.9 × 0.95 × 0.81 × 0.8)
battery_energy = night_time_energy / 0.55404
```

**Battery Capacity (kAh):**
```
battery_capacity = battery_energy / battery_nominal_voltage
battery_capacity = battery_energy / 12
```

**Example:**
- If `night_time_energy = 22.97 kWh`
- `battery_energy = 22.97 / (1 × 0.9 × 0.95 × 0.81 × 0.8) = 22.97 / 0.55404 = 41.45 kWh`
- `battery_capacity = 41.45 / 12 = 3.45 kAh`

---

### 1.5 Inverter & DC-DC Converter Sizing

**Inverter Rating (kVA):**
```
inverter_rating = pv_peak_power × 1.25
```

**DC-DC Converter Rating (kW):**
```
dcdc_sizing = inverter_rating
```

---

### 1.6 Grid Connection Sizing

**Grid Connection (kW):**
```
grid_connection_kw = peak_load_kw = total_daily_energy_kwh / 8
```

(Assumes 8 hours of peak usage)

---

### 1.7 Diesel Generator Sizing (Optional)

**Diesel Capacity (kW):**
```
diesel_capacity_kw = local_load × 1.1
```

(Only if `allow_diesel = True` and "diesel" in `preferred_sources`)

## 2. ECONOMIC ANALYSIS FORMULAS

### 2.1 Cost Constants

**Component Unit Costs (derived from Flask code):**
```
pv_cost_perkW = 17,846,400 / 594.92 = ₹30,004.81 per kW
battery_cost_per_kWh = 17,720,000 / (177.2 × 12) = ₹8,333.33 per kWh
inverter_cost_per_kVA = 5,949,200 / 743.65 = ₹8,001.88 per kVA
dcdc_cost_per_kW = 991,650 / 743.65 = ₹1,333.65 per kW
```

**Additional Component Costs (per kVA/kWh):**
```
add_cap_inv_dual_mode_per_kVA = 1,984,000 / 743.65 = ₹2,668.62 per kVA
add_sc_inv_dual_mode_per_kVA = 2,976,000 / 743.65 = ₹4,002.93 per kVA
add_cap_inv_on_grid_per_kVA = 992,000 / 743.65 = ₹1,334.31 per kVA
add_sc_inv_on_grid_per_kVA = 1,388,000 / 743.65 = ₹1,866.90 per kVA

add_cap_bat_dual_mode_per_kWh = 119,000 / (12 × 177.2) = ₹55.97 per kWh
add_sc_bat_dual_mode_per_kWh = 138,800 / (12 × 177.2) = ₹65.30 per kWh
```

**Installation & O&M:**
- Installation cost: 10% of equipment cost
- Annual O&M cost: 3% of (PV + Battery) cost

**Interest Rate:**
```
annual_interest_rate = 0.1 (10%)
```

---

### 2.2 Component Cost Calculations

**Solar Panel Cost:**
```
pv_cost = pv_cost_perkW × pv_peak_power
```

**Battery Cost:**
```
battery_cost = battery_cost_per_kWh × battery_energy
```

**Inverter Cost:**
```
inverter_cost = inverter_cost_per_kVA × inverter_rating
```

**DC-DC Converter Cost:**
```
dcdc_cost = dcdc_cost_per_kW × dcdc_sizing
```

---

### 2.3 Dual Mode System Costs

**Installation Cost:**
```
Installation_cost_dual_mode = 0.1 × (pv_cost + battery_cost)
```

**Annual O&M Cost:**
```
annual_om_cost_dual_mode = 0.03 × (pv_cost + battery_cost)
```

**Capital Cost:**
```
capital_cost_dual_mode = pv_cost + battery_cost + inverter_cost + dcdc_cost + Installation_cost_dual_mode
```

**Annual Cost (including interest):**
```
annual_cost_dual_mode = capital_cost_dual_mode × annual_interest_rate + annual_om_cost_dual_mode
```

---

### 2.4 On-Grid System Costs

**Installation Cost:**
```
Installation_cost_on_grid = 0.1 × pv_cost
```

**Annual O&M Cost:**
```
annual_om_cost_on_grid = 0.03 × pv_cost
```

**Capital Cost:**
```
capital_cost_on_grid = pv_cost + inverter_cost + Installation_cost_on_grid
```

**Annual Cost (including interest):**
```
annual_cost_on_grid = capital_cost_on_grid × annual_interest_rate + annual_om_cost_on_grid
```

---

### 2.5 Annual Energy Generation

**Solar Insolation Constants for Outage Scenarios:**
```
daily_solar_insolation = 5.02 kWh/m²/day
one_hour_outage_solar_insolation = 4.6 kWh/m²/day
two_hour_outage_solar_insolation = 4.2 kWh/m²/day
three_hour_outage_solar_insolation = 3.8 kWh/m²/day
```

**On-Grid System - Normal Operation (No Outage):**
```
# Note: The "1" in the formula represents n_panel = 1 (Flask override)
T_on = 365 × pv_peak_power × daily_solar_insolation × 1 × n_inverter
T_on = 365 × pv_peak_power × 5.02 × 1 × 0.9
T_on = 365 × pv_peak_power × 5.02 × 0.9
```

**Dual Mode System - Normal Operation (No Outage):**
```
# Note: The "1" in the formula represents n_panel = 1 (Flask override)
T_dual = 365 × pv_peak_power × daily_solar_insolation × 1 × n_inverter × n_dcdc
T_dual = 365 × pv_peak_power × 5.02 × 1 × 0.9 × 0.95
T_dual = 365 × pv_peak_power × 5.02 × 0.9 × 0.95
```

---

### 2.6 Cost of Energy Generation (Normal Operation)

**On-Grid System:**
```
cost_energy_on_grid = annual_cost_on_grid / T_on
```

**Dual Mode System:**
```
cost_energy_dual_mode = annual_cost_dual_mode / T_dual
```

---

### 2.7 Annual Revenue

**Revenue Rate:**
```
revenue_per_kWh = ₹8.0
```

**Annual Revenue:**
```
annual_revenue_on_grid = T_on × 8
annual_revenue_dual_mode = T_dual × 8
```

---

### 2.8 Cost of Energy Generation (Grid Outage Scenarios)

#### 2.8.1 On-Grid System - Daytime Outage

**Energy Generation During Outage:**
```
T_on_onehour = 365 × pv_peak_power × one_hour_outage_solar_insolation × 1 × n_inverter
T_on_twohour = 365 × pv_peak_power × two_hour_outage_solar_insolation × 1 × n_inverter
T_on_threehour = 365 × pv_peak_power × three_hour_outage_solar_insolation × 1 × n_inverter
```

**Cost of Energy:**
```
cost_energy_on_grid_onehour = annual_cost_on_grid / T_on_onehour
cost_energy_on_grid_twohour = annual_cost_on_grid / T_on_twohour
cost_energy_on_grid_threehour = annual_cost_on_grid / T_on_threehour
```

#### 2.8.2 On-Grid System - Nighttime Outage

**Energy Generation (unchanged):**
```
T_on_night = 365 × pv_peak_power × daily_solar_insolation × 1 × n_inverter
```

**Cost of Energy:**
```
cost_energy_on_grid_night = annual_cost_on_grid / T_on_night
```

#### 2.8.3 Dual Mode System - Daytime Outage (No Outage = 0 hours)

**Energy Generation:**
```
T_dual_zero = 365 × ((daily_solar_insolation × local_load) + 
                     (pv_peak_power - (local_load / (n_dcdc × n_inverter))) × 
                     daily_solar_insolation × n_dcdc × n_inverter)
```

#### 2.8.4 Dual Mode System - Daytime Outage (1, 2, 3 hours)

**Energy Generation:**
```
T_dual_onehour = 365 × ((daily_solar_insolation × local_load) + 
                        (pv_peak_power - (local_load / (n_dcdc × n_inverter))) × 
                        one_hour_outage_solar_insolation × n_inverter × n_dcdc)

T_dual_twohour = 365 × ((daily_solar_insolation × local_load × 1) + 
                        (pv_peak_power × 1 - (local_load / (n_dcdc × n_inverter × 1))) × 
                        two_hour_outage_solar_insolation × n_inverter × n_dcdc)

T_dual_threehour = 365 × ((daily_solar_insolation × local_load × 1) + 
                          (pv_peak_power × 1 - (local_load / (n_dcdc × n_inverter × 1))) × 
                          three_hour_outage_solar_insolation × n_inverter × n_dcdc)
```

**Annual Secondary Benefits (Savings from avoiding diesel):**
```
AS_one_hour = local_load × 365 × 1 × 29  (₹29 per kWh saved)
AS_two_hour = local_load × 365 × 2 × 29
AS_three_hour = local_load × 365 × 3 × 29
```

**Cost of Energy:**
```
cost_energy_dual_mode_onehour = (annual_cost_dual_mode - AS_one_hour) / T_dual_onehour
cost_energy_dual_mode_twohour = (annual_cost_dual_mode - AS_two_hour) / T_dual_twohour
cost_energy_dual_mode_threehour = (annual_cost_dual_mode - AS_three_hour) / T_dual_threehour
```

#### 2.8.5 Dual Mode System - Nighttime Outage

**Energy Generation:**
```
T_dual_night_onehour = 365 × (local_load × (daily_solar_insolation × 1 + 1) + 
                              daily_solar_insolation × n_dcdc × n_inverter × 
                              (pv_peak_power × 1 - (local_load / (n_dcdc × n_inverter × 1))))

T_dual_night_twohour = 365 × (local_load × 1 × (daily_solar_insolation + 2) + 
                              daily_solar_insolation × n_dcdc × n_inverter × 
                              (pv_peak_power × 1 - (local_load / (n_dcdc × n_inverter × 1))))

T_dual_night_threehour = 365 × (local_load × 1 × (daily_solar_insolation + 3) + 
                                daily_solar_insolation × n_dcdc × n_inverter × 
                                (pv_peak_power × 1 - (local_load / (n_dcdc × n_inverter × 1))))
```

**Annual Battery Cost (Grid charging for nighttime outage):**
```
Annual_battery_cost_onehour = local_load × 365 × 1 × 8  (₹8 per kWh from grid)
Annual_battery_cost_twohour = local_load × 365 × 2 × 8
Annual_battery_cost_threehour = local_load × 365 × 3 × 8
```

**Cost of Energy:**
```
cost_energy_dual_mode_night_onehour = (annual_cost_dual_mode + Annual_battery_cost_onehour - AS_one_hour) / T_dual_night_onehour
cost_energy_dual_mode_night_twohour = (annual_cost_dual_mode + Annual_battery_cost_twohour - AS_two_hour) / T_dual_night_twohour
cost_energy_dual_mode_night_threehour = (annual_cost_dual_mode + Annual_battery_cost_threehour - AS_three_hour) / T_dual_night_threehour
```

---

### 2.9 Simple Payback Period

**Dual Mode System:**
```
Simple_payback_dual_mode = capital_cost_dual_mode / (annual_revenue_dual_mode - annual_om_cost_dual_mode)
```

**On-Grid System:**
```
Simple_payback_on_grid = capital_cost_on_grid / (annual_revenue_on_grid - annual_om_cost_on_grid)
```

### Example 1: Technical Sizing

**Input:**
- `total_daily_energy_kwh = 50.0 kWh/day`

**Step 1: Calculate Local Load**
```
local_load = 50.0 / 24 = 2.083 kW
```

**Step 2: Calculate Day/Night Split**
```
day_time_energy = 50.0 × (7.03 / 13.01) = 27.03 kWh
night_time_energy = 50.0 × (1 - 7.03 / 13.01) = 22.97 kWh
```

**Step 3: Calculate PV Energy Generation**
```
# Note: n_panel = 1 (Flask override), not 0.8207
n_panel = 1
n_battery_roundtrip = 0.9 × 0.9 = 0.81

pv_energy_gen = (27.03 / (1 × 0.9 × 0.95)) + (22.97 / (1 × 0.9 × 0.95 × 0.81))
pv_energy_gen = (27.03 / 0.855) + (22.97 / 0.69255)
pv_energy_gen = 31.61 + 33.17 = 64.78 kWh
```

**Step 4: Calculate PV Peak Power**
```
pv_peak_power = 64.78 / 5.02 = 12.90 kW
```

**Step 5: Calculate Battery Energy**
```
battery_energy = 22.97 / (1 × 0.9 × 0.95 × 0.81 × 0.8)
battery_energy = 22.97 / 0.55404 = 41.45 kWh
```

**Step 6: Calculate Battery Capacity (kAh)**
```
battery_capacity = 41.45 / 12 = 3.45 kAh
```

**Step 7: Calculate Inverter Rating**
```

```

**Step 8: Calculate DC-DC Converter Rating**
```
dcdc_sizing = 16.13 kW
```

## 5. NOTES AND DISCLAIMERS

### 5.1 Formula Notes

1. **Panel Efficiency (n_panel):** The Flask code explicitly sets `n_panel = 1` (overriding the calculated value of 0.8207) and uses `n_panel = 1` in **ALL** calculations. This means:
   - `n_panel = n_module × n_temperature × n_dust` is calculated first (= 0.8207)
   - Then `n_panel = 1` is explicitly assigned (Flask override)
   - All subsequent formulas use `n_panel = 1`, not 0.8207
   - The "1" appears explicitly in formulas like `365 × pv_peak_power × daily_solar_insolation × 1 × n_inverter`

2. **Outage Scenarios:** The formulas for dual mode system during outages include complex calculations that account for:
   - Battery backup during outages
   - Solar generation reduction during daytime outages
   - Grid charging requirements for nighttime outages
   - Secondary benefits from avoiding diesel generator use

3. **Cost Calculations:** Component costs are derived from the Flask code's total project costs divided by installed capacity, providing realistic unit costs.

4. **Simple Payback Period:** Uses net revenue (revenue minus O&M costs) rather than gross revenue, providing a more conservative estimate.

### 5.2 Implementation Details

- All calculations match the Flask `solar-battery-calculation` endpoint exactly
- Results are rounded to 2 decimal places for display
- The implementation includes both dual mode and on-grid system calculations for comparison
- All outage scenarios (daytime and nighttime, 0-3 hours) are calculated and included in the response
