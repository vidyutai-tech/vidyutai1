🚀 HOW TO START THE APPLICATION
═══════════════════════════════════════════════════════════════════

Open THREE separate terminals:

┌─────────────────────────────────────────────────────────────────┐
│ TERMINAL 1: Backend (Node.js)                                   │
└─────────────────────────────────────────────────────────────────┘

cd backend
npm install
npm start

✓ Backend will run on: http://localhost:3000
✓ API available at: http://localhost:3000/api/v1
✓ Socket.IO ready for real-time updates


┌─────────────────────────────────────────────────────────────────┐
│ TERMINAL 2: Frontend (React)                                    │
└─────────────────────────────────────────────────────────────────┘

cd frontend
npm install
npm run dev

✓ Frontend will run on: http://localhost:5173
✓ Browser will auto-open the dashboard


┌─────────────────────────────────────────────────────────────────┐
│ TERMINAL 3: AI Service (Python) - OPTIONAL                      │
└─────────────────────────────────────────────────────────────────┘

cd ai-service
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
cd app
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000

✓ AI Service will run on: http://localhost:8000
✓ API docs available at: http://localhost:8000/docs

NOTE: Backend works without AI service using mock data!

🛠️ TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════

Port Already in Use:

  Backend:   lsof -ti:3000 | xargs kill -9
  Frontend:  lsof -ti:5173 | xargs kill -9
  AI:        lsof -ti:8000 | xargs kill -9
  
  Note: Port 5000 is used by macOS AirPlay Receiver, so we use port 3000

Module Not Found:

  Backend:   cd backend && rm -rf node_modules && npm install
  Frontend:  cd frontend && rm -rf node_modules && npm install
  AI:        cd ai-service && rm -rf venv && python3 -m venv venv

Can't Connect to Backend:

  1. Make sure backend is running first
  2. Check backend console for errors
  3. Verify ports in .env files match
